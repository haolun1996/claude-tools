# Third-party notices

lumen bundles no third-party code. Its color themes follow the published palettes of these projects, each under the MIT License:

| Theme | Palette by |
| --- | --- |
| catppuccin-mocha, catppuccin-latte | [Catppuccin](https://github.com/catppuccin/catppuccin) |
| dracula | [Dracula Theme](https://draculatheme.com) |
| nord | [Arctic Ice Studio, Nord](https://www.nordtheme.com) |
| tokyo-night | [enkia, Tokyo Night](https://github.com/enkia/tokyo-night-vscode-theme) |
| gruvbox-dark, gruvbox-light | [morhetz, gruvbox](https://github.com/morhetz/gruvbox) |
| rose-pine, rose-pine-dawn | [Rosé Pine](https://rosepinetheme.com) |
| everforest | [sainnhe, Everforest](https://github.com/sainnhe/everforest) |
| github-dark, github-light | [Primer, GitHub](https://primer.style) |
| one-dark | [Atom, One Dark](https://github.com/atom/atom) |
| solarized-dark, solarized-light | [Ethan Schoonover, Solarized](https://ethanschoonover.com/solarized) |

`neon` is lumen's own palette. lumen's behavior was designed with [prismantis](https://github.com/NahumLitvin/prismantis) as a reference; no prismantis code is included.

LaTeX formulas are typeset by [RaTeX](https://github.com/erweixin/RaTeX)'s `ratex-render`, a separate program the user installs; lumen only runs it.
